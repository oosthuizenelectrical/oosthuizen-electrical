Questions

Good to know

Should I start with backup or go straight to solar?

If load shedding or outages are the main worry, an inverter and battery is a good start. If you want lower bills, add panels. A hybrid inverter lets you start with backup and add solar later.

Do you install three-phase systems?

Yes. Three-phase inverter and solar work is done together with a trusted, registered three-phase electrician we work with, so it is properly signed off.

Can you work on a system someone else installed?

Yes. We do maintenance, fault finding and repairs on existing systems.

Do I need to register my solar system?

Grid-connected systems in Cape Town need to be registered with the City. We handle the full SSEG process for you, including the engineer sign-off. Read our SSEG registration guide.
